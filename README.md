 # Simplicate Customer Dashboard

Klantdashboard voor inzicht in project- en ureninformatie vanuit Simplicate.

## Doel

Het doel van dit project is het ontwikkelen van een overzichtelijk klantdashboard waarin gebruikers inzicht krijgen in hun projecten en de bijbehorende urenstatus.

De gebruiker moet onder andere kunnen zien:

* Projecten
* Urenbudget
* Geregistreerde uren
* Resterende uren


Het dashboard wordt gekoppeld aan Simplicate om project- en ureninformatie op te halen.

Daarnaast wordt authenticatie toegepast zodat alleen geautoriseerde gebruikers toegang hebben tot het dashboard.

## Technologie

De definitieve technologieën worden tijdens de analysefase bepaald.

Voorlopige richting:

* Frontend: Vue
* Backend: Ruby
* Data: Simplicate API
* Authenticatie: wordt tijdens het project bepaald

## Status

Project gestart.

Momenteel bevindt het project zich in de analysefase.

## Stageopdracht

Het ontwikkelen van een klantdashboard, gekoppeld met Simplicate via de API of MCP, waarmee klanten real-time inzicht kunnen krijgen in de urenstatus van hun projecten.
